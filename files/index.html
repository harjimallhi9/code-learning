// about

Harji is a freelance software developer based in Karnal, India, focused on real-time web systems — things that move, update, and respond live. Recent work includes a full-stack GPS location tracker built with Node.js, Express, Socket.io, and Leaflet.js, featuring a dark, mission-control-style dashboard.

Outside of client work, Harji creates tech content for a YouTube audience of budget-conscious students and young professionals, and is currently sharpening problem-solving fundamentals through Python.
