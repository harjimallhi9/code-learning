# Portfolio site

Plain HTML/CSS/JS — no build step, no dependencies. Open `index.html` in a browser to preview.

## What to edit

Search each file for `EDIT` comments — they mark everything you should personalize:

- **index.html**
  - Nav status text ("Available for freelance work")
  - About section copy (currently a draft based on your GPS tracker project)
  - Skills tags — add/remove to match what you actually know
  - Projects — project 1 is your real GPS tracker, projects 2–3 are placeholders (`[Project name]`)
  - Certificates — all three are placeholders (`[Certificate name]`, `[Issuing organization]`, `[Year]`)
  - Contact links — every `href="#"` needs your real GitHub, LinkedIn, and Instagram URL; also update the `mailto:you@example.com` address

## Deploying

Easiest free option: **GitHub Pages**.
1. Push these files to a GitHub repo.
2. Repo Settings → Pages → set source to your main branch.
3. Your site goes live at `https://yourusername.github.io/repo-name`.

Netlify or Vercel also work if you just drag-and-drop the folder.
